# 🏃 2026運動会 スケジュール管理アプリ

長田須磨地区 2026年運動会の準備スケジュールを、関係者全員でリアルタイムに共有・管理するためのアプリです！

👉 **アプリへのアクセスはこちら:** [https://SP-tomo.github.io/schedule-app](https://SP-tomo.github.io/schedule-app)

---

## 📱 アプリの使い方

このアプリは「今誰が何をやっているのか」「どこまで進んでいるのか」を共有するためのものです。どのスマホ・PCからアクセスしても、常に全員が同じ最新のスケジュールを見ることができます。

### 1️⃣ タスクの進捗を更新する（一番よく使う操作）
自分が担当しているタスクが進んだら、進捗（%）を更新してください。
1. タスク一覧から、自分が担当しているタスクをクリック（タップ）します。
2. 編集画面が開くので、**「進捗状況」のバーを右に動かして**現在のパーセントを合わせます。
3. なにか特記事項があれば「メモ」欄に入力します。
4. 右下の **「保存」** ボタンを押します（または `Ctrl+Enter`）。
> 💡 進捗が100%になると、自動的に名前に「✅ 完了」というバッジが付きます！

### 2️⃣ 新しいタスクを追加する
新しい準備作業が発生したら、追加して担当者を決めましょう。
1. 各項目の下にある **「＋ タスクを追加」** をクリックします。
2. **タスク名** と **担当者** を入力し、開始日・終了日をカレンダーから選びます。
3. 必要に応じて「メモ」を書いたら **「保存」** を押します。

### 3️⃣ タスクの順番を入れ替える
タスクの優先度が変わったときや、わかりやすく整理したいときに使います。
- パソコンの場合： タスクの左端にある **「⠿（6つの点）」をつかんでドラッグ** すると、好きな位置に並び替えられます。フェーズ（区切り）を飛び越えて別の場所に移動させることも可能です。
- スマホの場合： タスクの右端にある **「上下の矢印ボタン（🔼🔽）」** をタップすることで、順番を入れ替えることができます。

### 4️⃣ タスクを探す・絞り込む
タスクが増えてきて探しにくいときは、画面上部の「ツールバー」を使います。
- **🔍 検索ボックス:** タスク名、担当者名、メモの内容で検索できます（パソコンなら `Ctrl + F` で入力欄に移動します）。
- **ステータスフィルター:** 「未着手」「進行中」「完了」「遅延」のタスクだけを絞り込んで表示できます。
- **担当者フィルター:** 「西村さん」「南園さん」など、特定の担当者のタスクだけを表示できます。

## 🎨 その他の便利機能

- **ガントチャート（スケジュール帯）表示**
  画面右上の「📊（棒グラフアイコン）」を押すと、カレンダーの帯のような画面（ガントチャート）に切り替わります。いつからいつまでが作業期間なのか、視覚的にわかりやすくなります。
- **テーマ（背景色）の変更**
  画面右上の「🎨（パレットアイコン）」を押すと、アプリの色合い（黒、白、桜色、海色など）を自分好みに変更できます。この設定は自分のスマホ/PCにだけ保存されるので、自由に変えて大丈夫です！
- **フェーズ（大項目）の追加・編集**
  「フェーズ1 本番3週間前」のような大きな区切りを新しく追加する場合は、画面一番下にある「＋ フェーズを追加」を押してください。矢印「▼」を押すと、そのフェーズの中身を折りたたんで隠すこともできます。

---

## ⚠️ 注意事項

- **全員が同じデータを編集しています！**
  誰かがタスクを削除すると、他の皆さんの画面からも消えてしまいます（削除前には確認画面が出ます）。むやみに他の人のタスクを消さないよう注意してください。
- インターネットに繋がっていない状態（オフライン）で行った変更は保存されません。画面右上に「⚫ リモート同期中」と表示されていることを確認して使ってください。
